# AI Resume Screening System

## Description
AI Resume Screening System is a Java Swing application that helps HR teams screen resumes using Google's Gemini AI.

## Features
- Login System
- Upload PDF Resume
- Extract Resume Text
- Job Description Management
- AI Resume Screening using Gemini
- Candidate Ranking
- PDF Report Generation
- MySQL Database

## Technologies
- Java 17
- Java Swing
- MySQL
- Gemini API
- Apache PDFBox
- Gson
- OpenPDF
- Maven

## How to Run
1. Import the project into VS Code.
2. Configure MySQL.
3. Run the SQL script.
4. Add your Gemini API key.
5. Run `Main.java`.
